# Capabilities

- AI agents: typed tools, role-aware authorization, approvals, resumable clarification, traceable execution, evaluation, retrieval
- Product engineering: React, Next.js, TypeScript, Python, Go, FastAPI, REST, PostgreSQL, MongoDB, Prisma, SQLite
- Platform/infrastructure: AWS, Kubernetes/EKS, VM provisioning, Jenkins, Lambda, API Gateway, S3, SimCloud, environment readiness
- Enterprise systems: OAuth2, SOAP-to-REST modernization, AppleConnect, Access Manager/IDMS, RBAC/LDAP, service accounts, credentials, entitlements
- Operations: observability, Splunk, CloudWatch, incident debugging, capacity planning, runbooks, release validation, audit trails

## Operating style

- Works vertically from ambiguous problem to data model, API, UI, deployment, and operational feedback.
- Bridges customers/operators, product, architecture, engineering, security, QA, and release teams.
- Favors deterministic state, explicit evidence, fail-closed permissions, and inspectable outcomes.
- Strongest in environments where requirements are incomplete and the builder must create both the solution and the operating model.
